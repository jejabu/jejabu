## 🚀 Proyecto destacado

### AuditorIA

Plataforma modular de análisis y evaluación de eventos de seguridad desarrollada como proyecto práctico de ciberseguridad.

AuditorIA permite procesar eventos de seguridad, evaluar el riesgo de una organización, analizar el impacto de los eventos y generar recomendaciones de remediación.

**Tecnologías y componentes principales:**

- Python
- Flask
- Wazuh
- Linux
- Windows Server
- Active Directory
- Sysmon
- JSON
- Security Event Analysis
- Risk Scoring
- Security Automation

👉 **[Ver proyecto AuditorIA](https://github.com/jejabu/AuditorIA)**
